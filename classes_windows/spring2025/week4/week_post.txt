Why and when would you want to transform data?

Data comes in many shapes and sizes, but data processing is specific to which types of data it expects, and the format matters. All digital data has at some point been refined and altered to be understood by computers. In fact, computer science dedicates a large field of study and understanding to the handling and understanding of data. As data scientists, we will often find ourselves bridging gaps between the data types we have and the types we need.

First, we must understand what we want to accomplish. Do we want to train a machine learning algorithm? Do we want to visualize a linear regression? How about performing EDA to see which features impact binary classification? Each of these cases requires different requirements and understandings of data. A binary classification model can understand a target column that has 0/1 or true/false, but it cannot understand a column with 3 possible values. It also cannot understand a column with thousands of values. Does it mean binary classification is impossible? Not at all! This is where data transformation takes place.

Imagine we're building a binary classification to predict if the weather will be above 30 degrees. We happen to have a target column with the temperature. A simple modification to the column can turn each row's temperature value to value > 30. Now, a numeric column has been transformed to a binary column! Data transformation simply means we change data from one type to another, usually to better suite our needs or be better understood. It's important to note that althought data is transformed, we should always expect the truthiness of data to be retained. So while the temperature column has changed to binary, the data itself hasn't been altered.

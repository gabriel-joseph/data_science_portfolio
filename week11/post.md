How are linear regression models evaluated?

Linear regression is a model that can predict a dependent variables based on independent variables. The influences on the dependent variable can range from 1 to many independent variables. When training, a linear regression model will study the dependent variable as a line charted on a graph, with the simply y=mx+b formula we're acquainted with. As it plots variables with a strong dependence with independent variables, the model will find an appropriate pattern within the data set. Now the model is ready for evaluation!

Like all other machine learning models, linear regression can only truly be assessed when evaluating unseen data. Suppose a linear regression model can predict the number of tickets sold using the temperature of the dat of an event. The model would train on 85% of the data and it might see a low number of ticket sales when the temperature is 30 and 40 degrees. But as the temperature rises, the model will see that ticket sales also increase, and therefore a linear relationship is drawn. With the remaining 15% dataset, we can then provide the model with various temperatures, such as 30, 77, and 62 degrees fahrenheit. We then move on to scoring.

Evaluations are scored, similar to students taking a test. Common evaluation metrics are Mean Squared Error (MSE), Root Mean Squared Error (RMSE), and Mean Absolute Error (MAE). MSE measures the average of the squared differences between predicted and actual values, giving more weight to larger errors. RMSE is the square root of MSE and provides error in the same units as the dependent variable, making it easier to interpret. MAE, on the other hand, calculates the average of the absolute differences between predicted and actual values, giving a straightforward measure of prediction error. Lower values for these metrics indicate a better performing model.

Data scientists have to pick and choose which evaluation metrics they prefer and create scoring reports to document their findings. However, the most important evaluation of linear regression is to plot the predict values and see how close the model was to plotting on the line/slope.
